# Teaching and digital learning

A collection page of live classroom business games: a simulated class playing the Fashion Market Game and a single-player version, with learning outcomes and a session plan.

**Live page:** https://farzad-vaziri.github.io/teaching-and-digital-learning/

One static page (`index.html`) served by GitHub Pages from `main`. Images are in `assets/previews/`, and fonts (Lexend, SIL Open Font License) are self-hosted in `assets/fonts/`. There is no build step.

Every dashboard on the page links to its live Streamlit app.
